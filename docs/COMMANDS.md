# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/torch` | Light a torch for Gold (default mode), or view the longest burn record | `` | `/torch [longest/price/reload]` |
| `/torchpass` | Pass the torch to another online player | `` | `/torchpass <player>` |
| `/joint` | Light a joint for Gold when unlock-joint is enabled, or view the longest burn record | `` | `/joint [longest/price/reload]` |
| `/pass` | Pass the active torch/joint to another online player | `` | `/pass <player>` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `roothaste.use` | Light and pass the torch/joint | `true` |
| `roothaste.bypass-fee` | Light without paying Gold | `op` |
| `roothaste.reload` | Reload root-haste.yml | `op` |
| `roothaste.price` | View or set Gold price | `op` |
| `rootjoint.use` | Legacy alias of roothaste.use | `true` |
| `rootjoint.bypass-fee` | Legacy alias of roothaste.bypass-fee | `op` |
| `rootjoint.reload` | Legacy alias of roothaste.reload | `op` |
| `rootjoint.price` | Legacy alias of roothaste.price | `op` |
| `roottorch.use` | Legacy alias of roothaste.use | `true` |
| `roottorch.bypass-fee` | Legacy alias of roothaste.bypass-fee | `op` |
| `roottorch.reload` | Legacy alias of roothaste.reload | `op` |
| `roottorch.price` | Legacy alias of roothaste.price | `op` |
